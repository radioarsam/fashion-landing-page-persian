## 🖼️ پیش‌نمایش

یک لندینگ پیج بلند و حرفه‌ای در زمینه **مدلینگ و فشن** با ۳ سکشن اصلی:

| سکشن | توضیح |
|------|--------|
| **Hero** | معرفی آژانس + تصاویر مدل‌های لوکس + لوگو برندهای مطرح |
| **کالکشن‌ها** | گرید کارت‌های کالکشن با الهام از Gucci، Chanel، Dior، LV |
| **مدل‌ها** | معرفی چهره‌های مدل + CTA همکاری |

تصاویر از **Unsplash** (رایگان و با کیفیت بالا) انتخاب شده‌اند و حس برندهای جهانی را منتقل می‌کنند.

## 🛠️ اجرا محلی

```bash
# کلون کنید
git clone https://github.com/radioarsam/fashion-landing-page-persian.git

# وارد پوشه شوید
cd fashion-landing-page-persian

# با هر سرور استاتیک باز کنید (مثال با Python)
python -m http.server 8000
```

سپس مرورگر را روی `http://localhost:8000` باز کنید.
